\# Number Base Converter (Java)



A console program that converts numbers between binary, octal, decimal and hexadecimal.



\## How it works

1\. Choose the input type from the menu (binary, octal, decimal or hex).

2\. Enter the number.

3\. Choose the output type.

4\. The program prints the converted value and returns to the main menu.

5\. Enter 0 at the main menu to exit.



\## Example

Input type: binary

Number: 1010

Output type: decimal

Result: 10



\## Run it

Open the project in Eclipse and run Main.java,

or compile and run from the command line:

javac src/Main.java

java -cp src Main
